# Klee — Preview

## Preview Path
`games/klee/index.html`

## How to Play
1. Select a shape (circle, square, triangle) from the toolbar
2. Select a color (red, yellow, blue, black)
3. Drag shapes from the toolbar onto the grid canvas
4. Tap empty grid cells to place color planes
5. Hold (>=400ms) on a placed shape to grow it (pitch rises)
6. Long-press empty canvas area (>=1s) to clear all

## Audio
- Red shapes: low tone (C3)
- Yellow shapes: mid tone (C4)
- Blue shapes: high tone (C5)
- Hold to grow: rising pitch drone, decays on release
- Balanced composition: resolved three-note chord
- Clear: descending sweep
- Dense canvas: soft dissonance
